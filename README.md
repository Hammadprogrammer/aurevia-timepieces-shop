# Aurevia Timepieces

Create a premium Pakistani watch e-commerce website for **AUREVIA Watches** only. Tagline: “Timeless Craft. Modern Elegance.” Build the complete React + TypeScript + Tailwind experience with polished premium international-brand visual design and a fully functional client-side commerce flow.

Pages/routes: Home, Shop, Men’s Watches, Women’s Watches, Luxury Watches, Smart Watches, Sports Watches, Product Details, Wishlist, Cart, Checkout, Order Success, Orders, About, Contact. Make all navigation and buttons work.

Catalog: add 40+ realistic, varied watch products across premium collections/categories. Each needs a professional name, brand, high-quality image, original and sale PKR pricing realistically in ₨4,999–₨49,999, discount, rating/review count, stock, colors, strap options, movement, case material, water resistance, warranty, SKU, description. Use product data and client state; never display terms like Static, Mock, Demo, LocalStorage, Backend unavailable, or Coming Soon.

Commerce behavior: persist cart, wishlist, checkout info, and orders across refreshes using browser storage. Add-to-cart should toast, update badges, work from listings/details. Cart supports quantity +/- , remove, automatic subtotal, discounts, delivery and total. Wishlist add/remove with badge. Checkout must collect full name, phone, email, full address, city, province, postal code, notes; Pakistani cities and PKR; payment methods COD, Easypaisa, JazzCash, bank transfer, card. Functional coupons AUREVIA10 10% and WELCOME500 ₨500. On place order validate all details, create realistic unique order ID, save order, clear cart and checkout data, then show a premium success popup containing exact confirmation copy, order ID, total, payment method, delivery address, estimated delivery date, with View Order and Continue Shopping buttons. Order immediately appears on Orders page.

Orders: show ID, date, items, quantity, total, payment, address, status, and professional timeline: Order Placed → Confirmed → Packed → Shipped → Out for Delivery → Delivered.

Design/UI: sticky responsive navbar containing AUREVIA; Home, Shop, Men, Women, Luxury, Smart, Sports, About, Contact; Search, Wishlist, Account, Cart. Use refined typography, watch-focused editorial imagery, gold/champagne accents, responsive layout, product filters/search/sorting as useful. Include loading animations/skeletons, tasteful transitions, toast notifications, polished empty states. Account can route elegantly to Orders. Test the entire flow Home → Product → Add Cart → Cart → Checkout → Payment → Place Order → Success Popup → Order Details → Orders. Resolve broken links, non-functional buttons, and console errors before finishing.
